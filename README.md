QUADRA — A Day That Stays

О проекте

QUADRA — веб-приложение для сохранения воспоминаний с помощью текста, фотографий и музыки.

Основные возможности

- Создание и сохранение воспоминаний.
- Анализ настроения текста.
- Добавление фотографий и аудиофайлов.
- Подбор музыкального сопровождения.
- Архив воспоминаний.
- Поиск и фильтрация записей.
- Светлая и тёмная темы оформления.

Технологии

- HTML5
- CSS3
- JavaScript

Как запустить

1. Скачать репозиторий.
2. Открыть файл "index.html" в браузере.
3. Для загрузки музыкального каталога требуется интернет.
